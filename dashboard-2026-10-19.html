What is Driving Volume?
Customer Adoption Growing — volume reflects product success
TM is seeing the highest inflow month (471 in Sep) because more customers are actively using the product. 55% of cases are customers learning to use TM features — not reporting failures. This is a healthy signal.
Winter '27 Readiness Activity (Sep surge)
18 Sep + 2 Aug cases mention "winter", "264", or "upgrade". Accounts include Bluvium, PostNL, Quentic, Rockwell Automation. Sandbox testing surfacing how-to gaps before GA — an opportunity for proactive enablement.
Context Definitions — new feature, growing adoption
68 cases (8.2% of volume) are Context Definition / field mapping questions. Customers are actively implementing this feature — documentation coverage is the gap, not the feature itself.
264 RC Upgrade — 26 cases, W-24001055 Closed
Field mapping regression to ASP post-264. Engineering resolved quickly (GUS W-24001055 closed). Cluster peaked and receded — no ongoing impact.

Where Engineering & Self-Serve Can Make the Most Impact
55% Customer Education — volume growth is adoption, not degradation

453 cases need enablement: Sep 269 vs Aug 184. Customers are actively using TM features and reaching support when self-serve falls short. Every KA published reduces this volume directly.

TTR under target — engineering quality reflected in resolution speed

Avg 7.4d TTR in Aug+Sep — best across TM · PC · PM. A direct result of engineering's investment in clear root causes, quick triage, and well-documented workarounds.

4% Documentation gap (32 cases) — customers asking for written guidance

Amendments, ramp deals, context definitions. 45 TM articles published this FY — these 32 cases point to the next highest-priority topics.

3% Error message quality (26 cases) — small investment, high self-serve deflection

26 cases where the error itself was unclear. Improving error strings in TLE, assetization, and order activation flows would deflect these cases without a KA.

5% Product bugs (40 cases) — context noted, IR clusters resolved

264 RC Upgrade cluster (26 cases) closed via W-24001055. Remaining 14 cases are across isolated patterns. No active incident impact.
